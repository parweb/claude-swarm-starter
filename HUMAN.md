# HUMAN.md

**Doctrine: only true human walls end up here.**

This file is the ONLY channel from the org to its human. It lists exclusively tasks an agent
CANNOT physically do:

- legal identity (KYC, ID uploads)
- bank accounts / payment instruments
- OTP / 2FA codes
- logins the human hasn't delegated
- explicit platform prohibitions (a platform bans automation → the human posts, or nobody does)

Everything else, the org does itself. "It would be faster if the human did it" is NOT a wall.
"I'm not sure I'm allowed" is NOT a wall — check, then act or escalate the *actual* prohibition.

Rules of the file:
- An agent hits a wall → writes an entry below → **continues with something else**. Never block on a human.
- Entries are actionable: what to do, how long it takes, what it unblocks.
- The human resolves entries on their own schedule. Resolved entries move to History with a ✅.
